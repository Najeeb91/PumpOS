# PumpOS V20 — Install & Onboarding

## Locked onboarding flow

Install
→ Create Owner
→ Station Details
→ Products
→ Tanks
→ Machines & Nozzles
→ Optional Team Setup
→ Station Ready
→ Owner Dashboard

## 1. Create Owner
Mandatory first account:
- Full Name
- Mobile
- Secure Password/PIN
- Owner role assigned by system

The installer must not require Manager or Salesman accounts.

## 2. Station Details
- Station Name
- Address
- Contact Number
- Business Day / timezone configuration
- Save & Continue

## 3. Products
Configure active products and selling rates.

## 4. Tanks
Configure tank, product, capacity, opening stock, opening dip and active dip chart.

## 5. Machines & Nozzles
Configure machine → nozzle → product → source tank mapping.

## 6. Optional Team Setup
Show:
- Add Manager
- Add Salesman
- Skip For Now

Adding a team member immediately creates their role-controlled account.
Skipping does not block station activation.

## 7. Station Ready
Show a concise readiness checklist:
- Owner ✓
- Station ✓
- Products ✓
- Tanks ✓
- Machines/Nozzles ✓
- Team: Optional

Then:
START USING PUMPOS

## Post-install
Owner can always go to:
Settings & Administration → Users & Roles

to add, deactivate or change authorized team members according to RBAC rules.

## UX rules
- Mobile-first at approximately 390×844.
- One primary action per screen.
- No unnecessary horizontal scrolling.
- Keyboard-safe forms.
- Clear progress indicator.
- Back navigation preserves entered values.
- Optional Team Setup is skippable.
- Never expose Owner-only administration to Manager/Salesman.
