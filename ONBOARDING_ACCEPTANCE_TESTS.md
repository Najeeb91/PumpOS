# Onboarding Acceptance Tests

1. Fresh install shows Create Owner as the first account setup.
2. Owner account can complete setup without Manager/Salesman.
3. Station details are saved before continuing.
4. Product configuration is required.
5. Tank configuration validates capacity/opening stock/dip chart.
6. Machine/nozzle configuration validates product/source tank mapping.
7. Team Setup offers Add Manager, Add Salesman, Skip For Now.
8. Skip For Now reaches Station Ready.
9. Added Manager receives Manager role only.
10. Added Salesman receives Salesman role only.
11. Owner can add users later from Users & Roles.
12. Manager/Salesman cannot access Owner administration.
13. Back navigation does not erase saved setup data.
14. Refresh/reload does not duplicate an account or station.
15. Every material setup mutation has an audit event.
